# 策略6入场时机与概率修正RR设计

## 1. 目标

在策略6现有强势启动、整理、形态、支撑、尾部和客观交易计划之后，增加两个相互独立的研究事实：

1. 入场时机状态机：区分形态存在、支撑回踩形成中、止跌确认和结构失效。
2. 概率修正RR：使用评估日之前的本股历史路径，估计在固定持有期内先到目标或先到止损的频率。

新增能力不得修改原 `identify_entry_archetype()`、客观目标、止损、正式评分和旧字段。实验默认关闭，只有2023-2024训练与2025验证同时通过门禁后才允许影响正式候选。

## 2. 入场时机状态机

状态固定为：

- `INVALID`：支撑失败、最近收盘有效跌破支撑下沿，或出现放量破位。
- `WAITING_BREAKOUT`：结构有效但价格仍在支点下方，沿用等待突破语义。
- `SUPPORT_FORMING`：价格位于支撑附近，但尚未形成足够止跌证据。
- `SUPPORT_CONFIRMED`：支撑附近同时出现不再创新低、收盘转强、收盘位置改善和缩量回踩中的至少三项，且没有失效证据。
- `BREAKOUT_CONFIRMED`：沿用现有放量、收盘位置和支点突破确认。
- `RECLAIM_CONFIRMED`：沿用现有失败突破回收触发。
- `NOT_APPLICABLE`：没有可执行入场原型。

止跌证据只读取最近5个交易日：

- 最新最低价不低于之前4日最低价。
- 最新收盘高于前一日收盘，或最近两日收盘连续改善。
- 最新收盘位置不低于0.55。
- 最近3日均量不高于此前20日均量的0.90。
- 最新收盘重新站上战术支撑或支撑区下沿。

状态机只描述当前时机，不累加正式总分。实验开启时，`INVALID` 才允许硬排除，未确认状态最多降为观察。

## 3. 概率修正RR

概率模型使用当前交易计划的真实风险距离、目标1距离和目标2距离，并换算为ATR倍数。对评估日前的历史锚点逐日重放：

1. 每个锚点使用当时可见的ATR14。
2. 以当前风险ATR倍数构造锚点止损，以当前目标ATR倍数构造锚点目标。
3. 在后续固定20个交易日内检查先到止损还是先到目标。
4. 同日同时触发时按现有回测规则执行 `STOP_FIRST`。
5. 未在期限内到达目标的样本按未命中处理，避免高估远目标。
6. 仅使用评估日前已完整走完持有期的锚点，禁止未来数据泄漏。

计算：

```text
P1 = 目标1历史命中数 / 历史锚点数
P2 = 目标2历史命中数 / 历史锚点数
ProbabilityAdjustedR = P2 * RR2 + (P1 - P2) * RR1 - (1 - P1) * 1R
```

要求 `P2 <= P1`。历史锚点少于60个时标记 `INSUFFICIENT_SAMPLE`，不得参与候选过滤。

## 4. 实验设计

新增默认关闭的研究开关：

- `entry_timing_enabled`
- `probability_rr_enabled`

实验顺序：

- E0：正式基线。
- E1：仅入场时机，未确认降级、失效排除。
- E2：仅概率修正RR，可靠样本下期望R低于门槛才降级或排除。
- E3：E1与E2最小组合，仅在两个单变量均入围时运行。

冻结重放分别统计全部候选和 `READY/KEY` 可执行候选，只用闭合交易计算胜率、PF和期望R。

## 5. 正式升级门禁

- 训练和验证期望R均大于0。
- PF均不低于1.20。
- 平均盈利R/平均亏损R不低于2.5。
- 验证期闭合交易不少于30笔。
- 固定风险最大回撤不超过20%。
- 高成本、70%成交率和延迟一天压力测试通过。
- 2026年OOS保持锁定。

未通过时保留诊断、测试和研究报告，所有生产开关继续为 `false`。
