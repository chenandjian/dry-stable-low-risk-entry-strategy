# 策略6 VCP形态质量评分设计

## 1. 目标

在策略6“历史正式候选的VCP持续观察池”中新增独立的VCP形态质量评分，用于排序、分级和解释哪些股票的VCP结构更标准。

本评分只评价VCP形态，不参与VCP入池、正式候选资格、交易分类、一票否决、策略总分或买卖决策。评分前后VCP持续观察池成员必须完全一致。

## 2. 适用范围与边界

评分对象必须已经同时满足：

1. `vcp_observation_eligible=true`，当前VCP结构仍有效。
2. `vcp_history_qualified=true`，当前VCP强势起点后曾按正式策略6产生非 `REJECTED` 候选。

评分不改变上述条件，也不修改现有VCP识别器、历史正式候选逐日重放、突破保留期、结构失效和退出审计规则。

VCP形态分不包含：

- 当前价格距离支点的远近。
- 当前VCP生命周期状态。
- 策略6正式 `total_score`。
- 盈亏比、市场指数、相对强度、支撑位或交易计划。

这些信息继续独立展示。过度延伸表示当前位置不理想，不代表历史VCP形态一定较差，因此不扣VCP形态分。

## 3. 架构

新增独立模块 `strategy6/vcp_quality.py`。评分函数接收当日可见个股K线和 `Strategy6VcpObservation`，返回独立评分结果。它不得反向修改VCP观察资格或策略6正式评估结果。

评分在VCP观察器完成结构识别之后执行。时间结构使用当日可见K线中的交易日索引计算，禁止用自然日差替代交易日数量，禁止读取评估日之后的数据。

评分模型固定为 `VCP_QUALITY_V1`。V1阈值不进入前端配置页，确保不同任务之间可比较。未来只有经过历史验证并升级模型版本后才允许调整阈值。

## 4. 评分公式

总分为六个维度之和，范围为0至100。各分项和总分均取整数，分档边界使用包含上限的比较。所有非负平均分统一使用 `floor(value + 0.5)` 舍入，禁止依赖编程语言可能不同的银行家舍入行为。

### 4.1 收缩层次：20分

| 有效收缩轮数 | 得分 |
| --- | ---: |
| 2轮 | 12 |
| 3轮 | 17 |
| 4轮及以上 | 20 |

少于2轮不构成当前VCP结构，评分结果应为未评分。

### 4.2 振幅递减：25分

#### 相邻振幅收缩比例：12分

对每次后续收缩计算 `本轮振幅 / 上轮振幅`，按下表计分，多轮取算术平均并按统一规则舍入为整数。

| 比例 | 得分 |
| --- | ---: |
| `<=0.35` | 12 |
| `<=0.50` | 10 |
| `<=0.65` | 8 |
| `<=0.80` | 5 |
| `<=0.90` | 2 |
| `>0.90` | 0 |

#### 最后一轮振幅：8分

| 最后一轮振幅 | 得分 |
| --- | ---: |
| `<=3%` | 8 |
| `<=5%` | 6 |
| `<=8%` | 4 |
| `<=10%` | 2 |
| `>10%` | 0 |

#### 第一轮深度合理性：5分

| 第一轮振幅 | 得分 |
| --- | ---: |
| `8%-25%` | 5 |
| `>25%-35%` | 3 |
| `>35%-45%` | 1 |
| 其他 | 0 |

### 4.3 成交量递减：25分

#### 相邻收缩量比：15分

对每次后续收缩计算 `本轮平均成交量 / 上轮平均成交量`，按下表计分，多轮取算术平均并按统一规则舍入为整数。

| 量比 | 得分 |
| --- | ---: |
| `<=0.50` | 15 |
| `<=0.65` | 12 |
| `<=0.75` | 9 |
| `<=0.85` | 6 |
| `<=0.90` | 3 |
| `>0.90` | 0 |

#### 最后一轮相对第一轮成交量：10分

| 累计量比 | 得分 |
| --- | ---: |
| `<=0.35` | 10 |
| `<=0.50` | 8 |
| `<=0.65` | 6 |
| `<=0.80` | 3 |
| `<=0.90` | 1 |
| `>0.90` | 0 |

缺失、非正数或无法计算的成交量不得获得对应分数，并输出数据不足警告。

### 4.4 低点稳定：15分

逐轮计算 `本轮低点 / 上轮低点 - 1`，按下表计分，多轮取算术平均并按统一规则舍入为整数。

| 低点变化 | 得分 |
| --- | ---: |
| `>=2%` | 15 |
| `>=0且<2%` | 13 |
| `>=-1%且<0` | 10 |
| `>=-2%且<-1%` | 6 |
| `>=-3%且<-2%` | 2 |
| `<-3%` | 0 |

### 4.5 时间结构：10分

先把收缩证据日期映射到当日可见K线的索引。VCP总周期定义为 `最后一轮低点索引 - 第一轮峰值索引 + 1`：

| 总周期 | 得分 |
| --- | ---: |
| 12-45个交易日 | 5 |
| 8-11或46-55个交易日 | 3 |
| 其他 | 1 |

每轮收缩腿间隔定义为 `低点索引 - 峰值索引`。间隔为1表示峰值后的下一个交易日即形成低点，属于单日收缩；间隔大于等于2表示至少经过两个完整交易日间隔：

| 收缩腿质量 | 得分 |
| --- | ---: |
| 每轮间隔均大于等于2 | 5 |
| 只有一轮是单日收缩 | 3 |
| 两轮及以上为单日收缩 | 0 |

如果最后一轮振幅小于1%，且该轮仅用一个交易日形成，则标记 `VCP_MICRO_CONTRACTION_NOISE`，最终总分最高限制为79分。

### 4.6 支点清晰度：5分

比较最后两轮收缩峰值收盘价，计算绝对差异比例：

| 峰值差异 | 得分 |
| --- | ---: |
| `<=3%` | 5 |
| `<=5%` | 3 |
| `<=8%` | 1 |
| `>8%` | 0 |

## 5. 等级

| 总分 | 等级代码 | 中文显示 |
| --- | --- | --- |
| 90-100 | `TOP` | 顶级VCP |
| 80-89 | `HIGH` | 高质量VCP |
| 70-79 | `GOOD` | 良好VCP |
| 60-69 | `NORMAL` | 普通VCP |
| 0-59 | `WEAK` | 结构偏弱 |

评分允许某次任务没有顶级或高质量VCP，不使用任务内百分位强行产生高等级。

## 6. 输出字段

保留全部旧字段，新增：

- `vcp_quality_score`
- `vcp_quality_grade`
- `vcp_quality_contraction_score`
- `vcp_quality_range_score`
- `vcp_quality_volume_score`
- `vcp_quality_low_score`
- `vcp_quality_time_score`
- `vcp_quality_pivot_score`
- `vcp_quality_reasons`
- `vcp_quality_warnings`
- `vcp_quality_model_version`

数据库新增列必须使用兼容迁移。旧任务缺少评分时返回空值，前端显示“未评分”，禁止解释为0分。策略6版本升级为 `4.5.0`，V4.4任务仍显示原VCP池，同时提示可重新扫描生成形态分。

## 7. 前端展示和排序

“VCP形态候选”表格调整为：

`股票 | VCP形态分/等级 | VCP状态 | 收缩次数 | VCP支点 | 结构低点 | 距支点 | 历史正式候选 | 策略总分 | 风险提示`

默认排序规则：

1. 有评分记录优先，按 `vcp_quality_score` 降序。
2. 同分按状态优先级：接近支点、突破确认、突破后、形成中、过度延伸。
3. 再按策略 `total_score` 降序。
4. 最后按股票代码升序，保证排序稳定。

候选详情展示总分、等级、六个分项、模型版本、评分原因和警告。CSV导出包含全部新增字段。评分标签不得使用“买入”“推荐”等交易含义。

## 8. 测试和验收

### 单元测试

- 覆盖六个维度的全部分档边界。
- 覆盖多轮平均、整数舍入和总分求和。
- 覆盖单日微小收缩79分封顶。
- 覆盖成交量缺失、非正数和收缩证据不足。
- 验证评分函数不修改输入对象，重复执行结果一致。
- 验证只使用评估日及之前的K线，时间结构按交易日计算。

### 集成测试

- 评分前后VCP结构资格和历史正式候选资格不变。
- 评分前后VCP池股票集合完全一致。
- 正式候选类型、`total_score`、交易计划和生命周期不变。
- 新字段可完整写入和读取SQLite，旧库可兼容迁移。
- 旧V4.4任务显示未评分但不丢失候选。
- 策略1至策略5不受影响。

### 前端测试

- 验证有评分优先、分数降序及全部同分规则。
- 验证未评分显示、六项明细、原因、警告和CSV导出。
- 验证评分标签不改变重点候选、观察候选和VCP池数量。

### 真实数据验收

使用最新任务相同本地个股和真实指数数据重新扫描，报告必须包含：

- 评分前后VCP池数量对比。
- 全部VCP股票的分数和等级。
- 前10名及六项得分明细。
- 五个等级的数量分布。
- 异常高分、异常低分和单日微小收缩样本核查。
- `002156`、`002281` 等已讨论样本的评分解释。

## 9. 风险控制

- 评分不能调用未来K线或未来指数数据。
- 评分不能成为新的入池条件或交易过滤条件。
- 不允许复用策略6 `total_score` 冒充VCP形态分。
- 不允许按本次任务排名或百分位修改绝对等级。
- 不允许为了产生顶级VCP而放宽分档。
- 评分模型发生任何公式变化时必须升级 `vcp_quality_model_version`，旧任务快照不得重算覆盖。

## 10. 非目标

- 本期不进行VCP评分与未来收益的回测调参。
- 本期不把评分阈值暴露到前端配置页。
- 本期不调整VCP识别、历史资格、正式候选和交易规则。
- 本期不修改策略1至策略5。
