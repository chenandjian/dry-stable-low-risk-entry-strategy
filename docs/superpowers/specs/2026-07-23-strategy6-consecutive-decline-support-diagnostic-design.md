# 策略6连续收跌结构诊断指标设计

## 1. 目标

在策略6候选结果中增加一个“连续收跌结构”诊断指标，帮助人工判断连续回落期间是否同时守住短期低点、且没有异常冲高。该指标只用于候选表、候选详情和导出展示，不参与评分、硬过滤、候选分类、生命周期或交易计划。

## 2. 指标口径

以评估日为最后一根K线，从后向前统计连续收跌交易日：

1. 当日收盘价严格低于前一交易日收盘价，记为一个收跌日。
2. 遇到首个收盘价大于等于前一交易日收盘价的交易日后停止统计。
3. 取整个连续收跌区间的最低价 `decline_low`。
4. 取评估日向前最近5个交易日（包含评估日）的最低价 `five_day_low`。
5. 最近5日先排除连续收跌区间，再以剩余交易日最低价作为 `five_day_reference_low`；必须满足 `decline_low >= five_day_reference_low`，相等允许通过。
6. 连续收跌达到5日及以上时，最近5日完全包含在连续收跌区间内，因此该低点条件必然无法通过。
7. “未创5日高”继续沿用逐日判断：每个收跌日 T 的最高价不得严格超过其此前4个交易日最高价；相等允许。
8. 不使用首个收跌日作为固定低点基准，也不要求最低价逐日抬高。
9. 当且仅当连续收跌天数不少于3、连跌区间最低价不低于5日窗口内非收跌区间参考低点、且每个收跌日均未创滚动5日新高时，组合指标判定为通过。连续收跌占满5日时因没有参考样本而不通过。

## 3. 输出字段

新增以下策略6诊断字段：

- `consecutive_down_days`：截至评估日的连续收跌天数。
- `consecutive_down_low`：连续收跌区间最低价；无连续收跌时为空。
- `consecutive_down_structure_version`：当前固定为 `CONSECUTIVE_DOWN_INTERVAL_5D_V2`，用于隔离此前错误口径产生的历史任务。
- `consecutive_down_structure_pass`：是否同时满足“至少3日、连跌低点不是5日最低、未创滚动5日高”。
- `consecutive_down_no_new_streak_low`：兼容字段；新任务表示连跌区间最低价是否不低于5日窗口内非收跌区间参考低点。数据库列名保持不变，避免破坏旧API。
- `consecutive_down_min_low_margin_pct`：连跌区间最低价相对5日参考低点的比例；大于等于0通过，相等为0并允许通过。
- `consecutive_down_max_high_break_pct`：区间内最高价相对其此前4日最高价的最大突破比例；小于等于0表示未创滚动5日新高，数据不足时为空。

旧任务版本列保持 `NULL`。即使旧记录已有同名数值字段，前端也必须显示“未计算”，不得套用新口径解释。

## 4. 数据链路

1. `strategy6/indicators.py` 计算诊断指标并写入 `Strategy6Indicators`。
2. `Strategy6Evaluation.to_candidate_dict()` 输出字段。
3. `scanner/db.py` 使用兼容迁移新增列，并完成候选写入、读取和布尔反序列化。
4. 策略6 API 沿用现有候选接口，无需新增接口。
5. `Strategy6Results.vue` 在正式候选表和候选详情中展示，并加入候选CSV导出。

## 5. 前端展示

正式候选表以及“VCP确认候选”“VCP早期观察”共用的VCP观察表均新增“连续收跌结构”列，并作为一个组合指标展示：

- 满足：`3日 · 守5日参考低 · 未创5日高`
- 连跌不足3日：`2日 · 未满足`
- 连跌达到3日但发生破位或创新高：显示对应未通过原因
- 连跌区间最低价低于5日参考低点：显示`跌破5日参考低`
- 旧任务无字段：`未计算`

VCP两个板块继续复用同一候选记录和格式化函数，不单独计算指标，不改变VCP质量分、观察池准入、分组或排序。

候选详情展示连续收跌天数、区间最低价、是否守住和最弱余量。

## 6. 兼容与边界

- 不新增配置项，阈值固定为3个收跌日和最近5个交易日窗口，避免无必要参数化。
- 不修改策略1至策略5。
- 不修改策略6扫描入口和旧API。
- 新增版本字段采用SQLite兼容加列；不回填历史任务，也不破坏旧字段读取。
- 不修改任何评分函数、硬过滤函数、分类函数和生命周期函数。
- 回测按评估日截断后的可见K线计算，禁止读取未来数据。

## 7. 测试

1. 连续3日收跌，区间最低价不低于5日窗口内非收跌区间参考低点，且逐日未创滚动5日新高时为真。
2. 连跌区间最低价等于最近5日最低价时为假。
3. 连续收跌达到5日时为假。
4. 前复权价格包含多位小数时，相同原始低点不得因展示精度四舍五入而误判为严格大于。
5. 连续3日收跌但其中一天创滚动5日新高时为假。
6. 只有2日连续收跌时组合指标为假。
7. 平收或上涨中断连续计数。
8. 前置数据不足时不得误判为真。
9. 新字段通过候选字典、SQLite和API完整往返。
10. 旧任务空字段保持空值。
11. 连续收跌期间低点可以低于首个收跌日，但整个区间最低价不得低于5日窗口内非收跌区间参考低点。
12. 相同K线加入该诊断前后总分、拒绝原因和候选分类完全一致。
13. 前端正式候选表、VCP观察表、详情和CSV均展示新字段。
