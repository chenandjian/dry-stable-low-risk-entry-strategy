# 策略6 VCP历史候选资格连续性设计

## 1. 目标

策略6的“VCP形态候选”只能继承仍然有效的历史正式候选资格。历史候选日至当前VCP第一轮起点之间，如果价格结构已经发生深度破坏并进入明确下降趋势，旧资格必须失效；股票只有再次成为策略6正式候选后，才能建立新的VCP跟踪周期。

本次只增强策略6历史资格判断，不修改策略1至策略5，不改变策略6扫描入口、正式候选规则、VCP轮次算法和旧输出字段。

## 2. 根因

当前 `evaluate_vcp_candidate_history()` 只要在强势起点到评估日之间找到任意一次非 `REJECTED` 结果，就永久返回历史资格通过。它没有检查该候选日至VCP第一轮起点之间是否发生深度回撤、长期空头排列或原结构失效。

真实样本 `600028` 在2026-03-05以6.92元进入观察候选，至2026-05-18的VCP第一轮起点已跌至5.03元，跌幅27.31%；49个交易日中46日低于MA20，起点满足 `close < MA20 < MA50 < MA120`。该历史资格已经失效，不能继续支持5月后的VCP观察结构。

## 3. 连续性规则

对每个历史正式候选，使用当日可见数据检查候选日到VCP第一轮起点的连续性。候选日在VCP起点当日或之后时，不执行起点前连续性淘汰，仍由现有VCP结构和基础过滤负责。

历史资格出现以下任一情况即失效：

1. VCP起点收盘相对历史候选日收盘跌幅超过15%。
2. 候选日至VCP起点的最大收盘回撤超过20%。最大回撤按区间滚动最高收盘价计算，不能只比较首尾价格。
3. 截至VCP起点存在至少5个连续交易日满足 `close < MA20 < MA50`，且VCP起点当日仍满足该空头排列。

三条规则分别覆盖价位永久下移、期间深跌后弱修复和持续下降趋势。间隔天数本身不作为失效条件，避免误杀长时间但结构健康的横盘整理。

阈值作为策略6配置保存：

- `vcp_history_max_start_loss_pct: 0.15`
- `vcp_history_max_drawdown_pct: 0.20`
- `vcp_history_bearish_trend_days: 5`

## 4. 历史候选选择

仍按日期倒序重放正式策略6。发现非 `REJECTED` 候选后：

1. 若连续性有效，立即返回该候选并通过历史资格。
2. 若最新候选连续性失效，立即返回历史资格不通过；更早的旧候选不能救回已经失效的生命周期。
3. 若失效之后出现新的正式候选，倒序重放会先找到新候选，并以新候选建立新的资格周期。

这样不会永久封禁股票；后续重新成为正式候选即可形成新的有效资格。

## 5. 兼容性

- 保留现有 `vcp_history_qualified`、日期、类型、分数和来源字段。
- 不改变策略6正式候选、观察候选和拒绝候选的判定。
- 不修改VCP轮次和质量评分；本次只修正观察池准入的历史资格链。
- 旧任务不重算；新扫描和新回测按新规则执行。

## 6. 验证标准

1. `600028` 在2026-07-17不再取得VCP历史资格。
2. 候选后长期横盘、回撤受控且没有持续空头排列的样本继续通过。
3. 深跌后反弹到接近原价但区间最大回撤超过20%的样本失效。
4. 价格跌幅不足15%，但持续空头排列至少5日的样本失效。
5. 旧调用方不传VCP起点时保持原行为，避免API破坏。
6. 策略1至策略5测试不受影响。
