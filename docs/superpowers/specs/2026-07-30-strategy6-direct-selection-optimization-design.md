# 策略6直接选股优化设计

## 1. 目标与边界

本阶段继续使用策略6现有主链：强势启动、独立整理、形态、支撑、尾部、客观盈亏比和候选分层。不得修改策略1至策略5，不得启用已经被历史研究否决的BOX/Brooks正式入口，不得使用2026年OOS调参。

所有新增规则先作为独立诊断事实进入历史快照；只有单变量训练、验证和压力测试通过后，才允许影响正式候选。生产默认配置必须保持全部实验开关关闭。

## 2. 为什么调整开发顺序

评分是末端汇总层。支撑确认、保守RR、RS趋势、尾部恶化和所属市场都会改变评分输入，如果先修改总分，后续实验无法归因且必须重复调参。

调整后的顺序：

1. 冻结正式基线并建立评分审计。
2. 计算但不使用独立诊断事实。
3. 对每条选股规则做单变量冻结重放。
4. 仅对入围规则执行完整引擎回测。
5. 输入稳定后再校准评分。
6. 最后执行组合验证和压力测试。

## 3. 基线评分审计事实

冻结任务 `s6bt-772c046cb6c982f61fc5` 的241笔闭合交易显示：

- 形态分众数为1，占95.02%。
- 支撑分众数为20，占95.85%。
- 客观RR分众数为10，占90.04%。
- 总分与R收益不单调。
- 六个分项之间没有达到0.70的正相关重复证据。
- 形态分与RR分反而呈明显负相关，Spearman为-0.634。

因此当前问题不能简单表述为“多个分项重复奖励同一事实”。更准确的判断是：形态、支撑和RR分布严重饱和或失衡，无法有效区分交易结果。禁止在没有新实验前凭主观设置联合上限或新权重。

## 4. 独立诊断事实

`S6_SELECTION_DIAGNOSTICS_V1` 输出：

- RS5、RS10、RS20、RS60和RS趋势。
- 股票所属宽基指数及其同日状态。
- 支撑确认状态：`CONFIRMED/PARTIAL/PENDING/FAILED`。
- 尾部近期状态：`STABLE/FORMING/DETERIORATING/UNKNOWN`。
- 保守RR：沿用已有第一客观压力目标的 `objective_rr_1`，不重新制造目标价。

这些字段不得自行改变候选资格。

## 5. 单变量实验

实验开关位于 `strategy6.selection_optimization`，默认全部为 `false`：

| 实验 | 作用 |
|---|---|
| E1 支撑确认 | 明确失败时排除，未确认时最多WATCH |
| E2 保守RR | 用 `objective_rr_1` 替代 `objective_rr_2` 参与现有RR门槛 |
| E3 RS衰减 | RS趋势为FADING时最多WATCH |
| E4 尾部恶化 | `DETERIORATING` 时排除 |
| E5 所属市场 | 对应指数弱或风险状态时最多WATCH |
| E6 组合 | 只用于验证单变量入围后的最小组合 |

末端规则不改变指标、形态、支撑和交易计划，可先对同一批冻结信号确定性重放。只有会新增信号或改变交易计划的后续方案才必须从个股日线完整重建。

冻结重放必须分别统计全部保留候选和可执行候选。`READY_CANDIDATE`、`KEY_CANDIDATE` 才计入可执行交易；被降为 `WATCH_CANDIDATE` 后不得继续混入可执行收益，否则降级规则的效果会被掩盖。旧任务缺少新诊断字段时，只允许按原信号日截断个股和指数数据重建诊断，不得读取信号日后的数据，也不得改写原交易结果。

## 6. 评分校准门禁

评分修改必须同时满足：

1. 闭合交易不少于60笔。
2. 明确指出重复的市场事实和对应分项。
3. 分项正相关达到预设阈值，且收益归因支持去重。
4. 去重后高分组的期望R或PF表现出训练、验证一致的单调改善。
5. 不同时修改评分权重和候选门槛。

相关性只能触发实验，不能自动生成生产权重。

## 7. 正式升级门禁

- 训练和验证期望R均大于0。
- PF均不低于1.20。
- 平均盈利R/平均亏损R不低于2.5。
- 固定风险最大回撤不超过20%。
- 训练和验证合计至少60笔，验证至少30笔。
- 高成本、70%成交率和延迟一天压力测试全部通过。
- 2026年OOS继续锁定。
- 未通过时保留诊断和研究代码，正式配置不变。
