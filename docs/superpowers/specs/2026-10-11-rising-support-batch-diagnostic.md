# 批量评分低点抬高支撑诊断 V1

## 边界

用户认可的最新样本方案，仅接入批量评分展示和筛选，不接入正式策略6入口、评分、排序、候选分类、生命周期、扫描或数据库候选表；不改变策略1-5。固定版本 `RISING_SUPPORT_ZONES_V1`，不按股票代码设置例外。

## 规则

1. 使用本地前复权OHLC，至少60根完整日线。日期必须严格递增且有效；非有限值、非正价格或非法OHLC返回未知，不伪填为不符合。
2. 使用完整已知历史初始化Wilder ATR14并顺序识别回调，最终仅比较低点发生于最近60根日线内的支撑区。不搜索任意历史成功区间来救回当前结果。
3. 收盘从已知峰值回落至少当前1个ATR，进入回调；本轮最低价随后更新时，重新起算确认。
4. 低点之后至少两根日线，最近两次收盘均高于低点，最新收盘至少回升到低点加低点当天1个ATR，才成为已确认低点。输出低点日和确认日，不提前赋予历史确认资格。
5. 相邻回踩可合并为同一区域：低点总价差不超过该区域首次低点当天0.5个ATR；ATR宽度固定，不滚动扩大。保留回踩之间全部实际日线的最低价、日期、已确认回踩次数及最后确认日。
6. 比较最近两个或三个支撑区域，任一有效链可通过。区域代表价取真实最低价，至少一次相对此前区域最高基准抬高超过1%；其他区域最多向下容错1%，基准只上移、不下移。
7. 最新区域最后一次已确认回踩之后，任何最低价低于基准99%，或收盘低于基准，均使该链失效。等于最低价容差边界允许，但收盘须收回支撑。失效后不会仅因次日反弹自动救回同一条链。
8. 最新尚未确认的回调仅输出pendingLow，不升级成新支撑。它若已经破坏旧支撑，仍使旧链失效。

## 容错口径

同区合并的0.5ATR与区域之间的1%容错是两个不同判定：同区低点差异可能超过1%，但区域价必须取真实最低价。禁止使用较高低点替代较低低点，或宣称合并前被刺破的高位支撑仍有效。固定区域宽度限制连续下降的累计幅度，但不能证明任何高波动股票均不产生误判。

## 接口与页面

批量评分结果新增 `risingSupport`：matched、status、reason/中文reasonText、evaluationDate、windowStart、zones、supportPrice、distancePct、pendingLow及模型版本。

matched为true/false/null；null表示数据不足/异常，不应当显示成否。supportPrice在不符合时可能是被破坏的参考基准，须结合matched和原因阅读，不代表有效买入支撑。distancePct为 `(最新收盘/参考支撑-1)*100`。

页面在量能趋势之后新增“低点抬高（支撑）”，支持全部/是/否/数据不足或未计算；符合时标红。详情显示每个区域的起止、最低价日期、回踩次数、确认日期和未确认低点；清除筛选及TradingView导出沿用现有机制。

## 验证要求

覆盖真实抬高、下降、持平、累计下降、固定合并宽度、区间内最低价、支撑破坏、相等边界、未确认低点、数据不足/异常、日期重复、输入不可变、旧评分排序隔离及页面筛选清除/导出。以用户给出的11只本地股票复核结果为9符合、2不符合，不为保持样本通过修改阈值。
