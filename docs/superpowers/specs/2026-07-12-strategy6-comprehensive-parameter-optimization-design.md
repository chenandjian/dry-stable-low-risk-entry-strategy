# 策略6全面参数调优设计

## 1. 目标与边界

在策略6现有生产入口 `StrongVcpTailEngine.evaluate_at()` 上完成全面、分层、可恢复的参数研究，以稳健盈亏比为第一目标，验证流动性、市场、强势启动、形态、支撑、原尾部量干价稳、箱体、紧密K线、评分、盈亏比及成交执行参数。

本期只生成参数建议和差异，不自动修改 `config.yaml`。2026-01-01起OOS继续锁定，不参与搜索、筛选、排序或二次调参。策略1至策略5不在修改范围内。

## 2. 已有证据

- 2023-2025真实回测覆盖5529只当前股票池；4793只完成评估，736只历史不足。
- E0原路径31笔，期望R -0.108，PF 0.834。
- E1默认双路径184笔，期望R -0.275，PF 0.537。
- BOX-only 153笔，期望R -0.310，PF 0.483。
- 已运行3组箱体联合参数，没有组合通过样本、期望、PF和回撤硬门槛。
- 当前结果只能否定默认BOX扩张，不能代表策略6其他参数已优化。

## 3. 优化目标

### 3.1 第一目标

- 验证期期望R不低于0.10。
- 验证期PF不低于1.20。
- 平均盈利R与平均亏损R之比不低于2.50。
- 固定风险组合最大回撤不超过20%。

### 3.2 样本和稳定性门槛

- 验证期可成交交易不少于30笔。
- 验证期关键指标至少保留训练期的60%；训练期为负时不得用该规则规避验证期硬门槛。
- 邻域至少60%的参数集通过基础约束，邻域稳健分中位数至少为中心参数的85%。
- 前五只股票正利润贡献不超过55%。
- 单月正利润贡献不超过35%。
- 高成本、70%成交率和延迟一天压力场景不得同时出现负期望与PF低于1.0。

候选数量不是优化目标。只有低于样本门槛时用于拒绝结论，不能为了增加交易数降低风险和收益门槛。

## 5. 分阶段搜索流程

每层依次执行：

1. 默认参数基线。
2. 单参数或约束参数组敏感性。
3. 剔除训练期明显负期望、样本不足或单调恶化区间。
4. 对剩余稳定区间执行固定种子分层随机联合搜索。
5. 训练期只用于参数选择。
6. 2025验证期只用于确认，不根据验证结果反向新增参数组合。
7. 通过硬约束后计算Pareto和邻域稳定性。
8. 每层只冻结稳定平台，不选择孤立最高点。
9. 若整层无组合通过，保留上一层参数并记录 `KEEP_PREVIOUS_STAGE`。

## 6. 性能与恢复

- 新增参数阶段、试验清单和阶段状态模型。
- 参数集与股票形成二维可恢复进度；同一参数集内部按股票多进程。
- 每个参数集保存配置哈希、策略提交、数据版本、阶段和父参数集。
- 已完成参数集可直接汇总，FAILED参数集不得参与选择。
- 粗筛允许使用完整股票池但较短训练日期；进入候选区后必须在完整2023-2025区间重跑。
- 不允许缩小股票池冒充全量结果。
- 支持运行预算和提前拒绝，但提前拒绝只能基于已完成训练期硬门槛，不能读取验证期或OOS。

## 7. 防泄漏和防过拟合

- 所有信号按评估日As-Of重建。
- 无个股当日K线时不生成信号。
- 参数变化生成独立快照，不复用旧参数的箱体、形态、支撑或交易计划。
- 训练、验证和OOS严格隔离。
- 2025验证结果不得驱动下一轮搜索。
- OOS只保存范围、数据哈希和策略提交。
- 搜索排序不使用候选数量、胜率或总收益单一指标。
- 报告必须披露当前股票池幸存者偏差和历史证券状态缺失。

## 8. 输出与审批

必须输出：

- 全参数字典、参数类型、默认值、候选值和不参与调优原因
- 每层单参数敏感性、联合搜索、硬约束和淘汰原因
- 训练/验证、年度、月度、市场、形态、路径和候选等级分组
- 固定等权和固定风险组合
- Pareto前沿、邻域稳定性和收益集中度
- 高成本、低成交率和延迟压力结果
- 每日候选、订单、交易和参数明细CSV
- 推荐参数、备选参数、当前参数和差异
- `RECOMMEND / CONDITIONAL / KEEP_DEFAULT / REJECT / INSUFFICIENT_DATA`

只有人工批准推荐参数后，才允许另行升级生产配置和策略版本。全面调优本身不修改生产配置。

## 9. 验收标准

1. 七个参数层均有真实敏感性结果或明确、可验证的不参与原因。
2. 每个联合参数集独立重建历史信号。
3. 训练期选择与验证期确认隔离，OOS无收益访问。
4. 无FAILED参数集进入推荐。
5. 邻域、Pareto、集中度和压力测试均有实际结果；无候选时输出空结果和原因。
6. 生产 `config.yaml` 内容不变。
7. 策略1至策略5全部回归通过。
8. 最终报告可以追溯到Git提交、数据版本、参数集、逐股进度和候选快照。
