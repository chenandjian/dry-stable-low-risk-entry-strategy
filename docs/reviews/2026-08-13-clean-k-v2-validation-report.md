# Clean K V2 验证报告

## 1. 验证范围

- 数据库：`data/cuphandle.db`
- 价格口径：本地前复权日线
- 目标完整交易日：`2026-08-12`
- 默认分析周期：20个有效交易日
- 对比模型：`Clean K V1` 与修正版 `CLEAN_K_V2`
- 本功能仍是独立诊断工具，不参与策略6评分、候选资格或扫描入口。

## 2. 实现结论

V2在V1的ATR14_PREV、显著性门控和单根几何评分基础上增加：

1. 方向型扩张、双向冲突扩张和跳空反转扩张分类。
2. 使用P90/P10的稳健平台宽度，降低单根极端影线影响。
3. 高低点推进和双向回撤纪律。
4. 只接受有价格证据的合法复合结构转换。
5. 最近N日整体结果与当前有效结构分别判断。
6. 冲突K数量、结构反复破坏和当前切换边界硬门禁。
7. 旧字段继续映射到窗口结果，保留旧API兼容性。

## 4. 分布审计

从股票池前600只中，筛得573只有完整目标日数据且可计算：

| 指标 | 数量 | 比例 |
|---|---:|---:|
| V1整体通过 | 331 | 57.8% |
| V2整体通过 | 451 | 78.7% |
| V2当前结构通过 | 536 | 93.5% |

V2整体通过率提高的主要原因是允许平台、收缩和趋势之间的有序转换，不是降低原V1总分阈值。当前结构用于解释最近有效后缀，不等于交易信号；其通过率高于整体结果是设计预期，但后续仍需人工标注样本校准。

## 5. 防过拟合措施

- 复合结构必须有突破、恢复或消化证据，不能只因切开后分数变高。
- 真正宽幅反复走势触发 `CHAOTIC`，不得由切段搜索救回。
- 大Gap后反向扩张不能获得方向型大K豁免。
- 冲突型K超过窗口10%容忍线时，即使分数较高也不通过。
- 当前结构在整体不通过时，必须比分窗高至少8分且存在明确切换边界。
- 当前结构不得跨越已识别复合结构的最后一段。
- 不包含任何股票代码特例。

## 6. 性能

`300888`、120日窗口本地实测约1.90秒。当前功能按单股手工诊断使用，性能可接受；尚未接入全市场扫描，禁止据此推断全市场批量性能。

## 7. 残余风险

1. 当前真实样本尚未完成人工逐只结构标注，分数只能作为初始模型结果。
2. V2当前结构通过率较高，后续应基于人工标签观察误报，而不是直接继续收紧阈值。
3. Swing Pivot证据不足时使用逐日高低点推进作为降级估计，短窗口解释置信度弱于长窗口。
4. V2不得未经独立回测和人工审批接入策略6正式评分或候选过滤。
