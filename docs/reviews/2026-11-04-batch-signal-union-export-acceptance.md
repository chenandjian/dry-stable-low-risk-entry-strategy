# 批量评分信号合集导出验收

## 需求确认

用户确认四组条件取并集：满足任意一组即纳入，按股票代码去重。

1. 高低点收敛：是。
2. EMA极致缠绕评分等级：S、A+、A。
3. 跌不动（卖压衰竭）确认强度：强确认、极致确认。
4. K线集合形态：任意集合形态等级为S或A。

截图中的EMA确认状态和集合形态状态均为“全部”，故仅依据等级，不额外加上已确认或已匹配门槛。
“低点抬高”不是截图所选的“高低点收敛”，不加入额外条件。

## 实现

- `web/src/pages/Strategy6BatchEvaluation.vue`：在评分结果顶部新增“一键导出信号合集（N）”。
- `web/src/utils/batchSignalExport.js`：四组条件取并集，验证可导出的股票代码，保留原评分顺序并去重，不修改评分数据。
- 复用既有 `tradingViewExport.js`：生成带交易所前缀、英文逗号分隔的TXT，例如 `SSE:603976,SZSE:300604`。
- 文件名：`strategy6-batch-signal-union-YYYYMMDD-HHMMSS.txt`。
- 合集使用本次成功评分的全部结果，不受表格临时筛选和25只分页影响，也不自动改变筛选条件。
- 原“导出筛选结果”仍严格导出当前表格全部筛选结果，两者各自独立。
- 没有命中股票时按钮禁用，不生成空文件；错误列表股票不进入导出。
- 仅前端展示/导出，未改变扫描、评分、候选资格、排序、数据获取或生命周期。
