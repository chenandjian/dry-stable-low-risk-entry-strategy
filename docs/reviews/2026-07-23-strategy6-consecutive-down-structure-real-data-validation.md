## 1. 验证目标

验证策略6新增的纯展示指标“连续收跌结构”是否能在真实A股日线中按既定口径稳定识别：

1. 评估日向前连续至少3个交易日收跌，即当日收盘价低于前一交易日收盘价。
2. 每个收跌日的最低价均不低于该日之前5个交易日的最低价。
3. 每个收跌日的最高价均不高于该日之前5个交易日的最高价；相等不视为创新高。
4. 指标只用于前端展示和CSV导出，不参与策略6评分、过滤、候选分层和交易计划。

## 6. 验证结论

1. 真实数据能够筛出合理样本，指标并非恒真或恒假；通过率约为 `17 / 4992 = 0.34%`。
2. 低点和高点均按每个收跌日各自之前5个交易日滚动计算，没有把评估日或未来数据放入基准窗口。
3. 最低价与此前5日最低价相等允许通过；最高价与此前5日最高价相等也允许通过。
4. 指标只描述“连续收跌但日内高低点仍受近5日区间约束”，不等同于买入信号，也不代表趋势、量能、支撑和盈亏比已经合格。
