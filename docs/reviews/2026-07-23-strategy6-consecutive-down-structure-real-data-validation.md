# 策略6连续收跌结构真实数据验证报告

## 1. 最终规则

截至评估日连续收跌至少3个交易日。对连续收跌区间内的每一天 T：

1. `close[T] < close[T-1]`。
2. `low[T] >= min(low[T-4:T])`，等于旧低允许，只有严格跌破才失败。
3. `high[T] <= max(high[T-4:T])`，等于旧高允许，只有严格突破才失败。
4. 滚动5日包含当日，所以比较窗口是当日之前4个交易日。
5. 不使用首个收跌日作为固定基准，不要求最低价逐日抬高。
6. 指标只用于前端和CSV展示，不参与评分、过滤、候选分层或交易计划。

## 6. 验证结论

1. 最终实现符合“连续收跌日不能严格跌破滚动5日最低价，等于允许”的口径。
2. 不再使用首个收跌日锚定，也不要求最低价逐日抬高。
3. 指标仍是纯诊断字段，不改变策略6总分、拒绝原因、候选类型和生命周期。
4. 真实样本数量明显增加，这是删除错误首日锚定条件后的预期结果，不是扫描候选数量变化；该指标不参与入选。
