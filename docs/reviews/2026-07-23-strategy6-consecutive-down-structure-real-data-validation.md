# 策略6连续收跌结构真实数据验证报告

## 1. 最终规则

截至评估日连续收跌至少3个交易日，并满足：

1. `decline_low = min(连续收跌区间的low)`。
2. `five_day_low = min(最近5个交易日的low)`。
3. `decline_low > five_day_low`；相等也失败。
4. 每个收跌日最高价不得严格超过其此前4个交易日最高价；相等允许。
5. 连续收跌达到5日及以上时，低点条件必然失败。
6. 指标只用于前端和CSV展示，不参与评分、过滤、候选分层或交易计划。

- 历史逐日重放区间：`2026-06-10` 至 `2026-07-22`，共30个交易日

## 5. 000655排除证据

`000655 金岭矿业`截至`2026-07-22`连续收跌4日：

| 日期 | 收盘 | 最低 |
|---|---:|---:|
| 2026-07-17 | 6.50 | 6.45 |
| 2026-07-20 | 6.47 | 6.35 |
| 2026-07-21 | 6.45 | 6.39 |
| 2026-07-22 | 6.43 | 6.39 |

计算结果：

```text
连续收跌区间最低价 = 6.35
最近5个交易日最低价 = 6.35
6.35 > 6.35 = false
```

因此`000655`不符合“连续下跌这几日的最低价不是5日内最低价”，必须排除。

## 6. 浮点精度修复

前复权价格可能包含多位小数。实现必须用同一份未舍入原始低价比较，不能先把连跌低点四舍五入到4位再与原始5日低比较，否则可能把相同低点误判为严格大于。显示值仍保留4位，不影响内部判断。

## 7. 验证结论

1. 当前实现采用区间级严格比较，不再使用首日锚定或逐日低点比较。
2. 相等明确失败；`000655`已被真实数据验证排除。
3. 最新交易日真实通过样本为`301270`和`600162`。
4. 指标仍是纯诊断字段，不影响策略6总分、候选资格和生命周期。
5. 新任务写入模型版本 `CONSECUTIVE_DOWN_INTERVAL_5D_V1`；旧任务没有该版本时前端显示“未计算”，避免沿用错误历史语义。
