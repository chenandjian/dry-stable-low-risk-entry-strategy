# 策略6连续收跌结构真实数据验证报告

## 1. 新规则

组合指标必须同时满足：

1. 截至评估日连续收跌至少3个交易日，`close[T] < close[T-1]`。
2. 每个收跌日最低价不低于该日之前5个交易日的最低价。
3. 首个收跌日建立本轮低点基准，后续最低价不得低于该基准；相等允许，不要求逐日抬高。
4. 每个收跌日最高价不高于该日之前5个交易日的最高价；相等不算创新高。
5. 指标只用于前端和CSV展示，不参与策略6评分、过滤、候选分层和交易计划。

## 7. 结论

1. 新规则准确实现“连续收盘下跌，但日内低点不再向下扩展”的结构含义。
2. 最新日没有股票通过，说明该结构相对少见；最近30日仍有38次真实事件，不是不可触发条件。
3. 规则允许最低价持平、抬高或抬高后小幅回落，只禁止跌破本轮首个收跌日低点。
4. 本指标继续只做人工诊断展示，不影响任何策略6候选资格和评分。
