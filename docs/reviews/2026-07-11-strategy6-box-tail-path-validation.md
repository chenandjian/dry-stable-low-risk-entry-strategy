# 策略6稳定箱体尾部路径验收报告

## 1. 检查范围

- 策略6原有尾部价稳量干路径及单股扫描入口兼容性
- 稳定箱体窗口枚举、边界、独立测试、跌破、中枢和量缩判断
- K线紧密排列的实体、收盘集中、重叠、跳空、ATR及放量下跌判断
- ORIGINAL / BOX / BOTH / NONE 双路径合并、评分和候选分层
- 配置默认值、深层合并、后端校验和前端编辑
- SQLite兼容迁移、候选读写、Excel报告、前端详情和CSV导出
- 策略6版本、项目约束文档和自动化测试

## 2. 总体结论

实现覆盖了开发文档要求。原 `strategy6/dry_tail.py::evaluate_dry_tail()` 与策略6扫描入口签名未修改；新增箱体路径独立计算，并通过 OR 与原路径合并。紧密排列只用于箱体窗口择优和质量标签，不参与箱体硬通过，也不累加到最终尾部分数。

双角色验收期间发现并修复一项中高等级边界问题：原尾部非重叠量能基准不足时，默认量比 `0.0` 可能被箱体路径误判为极致缩量。现在量能基准不足会直接输出 `BOX_TAIL_VOLUME_BASE_INSUFFICIENT`，箱体路径不得通过。

当前未发现剩余中、高等级问题。

## 3. 关键实现结果

1. 箱体候选仅在强势启动后的整理阶段内枚举，窗口长度由配置控制，默认5至30个交易日。
2. 箱体结构边界排除最后两个完整交易日，最后两日只用于跌破及当前位置确认，避免破位日反向重定义箱体下沿。
3. 上下沿使用结构区间最高/最低收盘价；下沿和上沿测试均按至少间隔两个完整交易日去重，上沿测试仅诊断展示。
4. 箱体通过要求宽度、下沿测试、中枢、后半段量缩、当前价格区间、尾部量干、无放量下跌、关键支撑未破及箱体未破位全部成立。
5. 最优窗口按 `box_quality_score`、持续天数、箱体宽度、量缩比依次择优。
6. `tail_path` 支持 `ORIGINAL`、`BOX`、`BOTH`、`NONE`；`BOTH` 取两条通过路径较高分，失败箱体不会抬高原路径结果。
7. 紧密排列独立输出0至10分和 `BOX_COMPACT_READY`，不改变 `box_tail_pass`，也不进入最终 `tail_score`。
8. 旧候选字段未删除，新增字段通过SQLite兼容加列持久化；旧任务缺失字段时使用兼容默认值。
9. 策略6版本升级为 `4.1.0`，配置哈希覆盖新增嵌套配置。
