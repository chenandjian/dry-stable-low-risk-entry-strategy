# 涨跌停情绪指数S及MA5验收

## 需求和计算

严格使用用户截图公式：`S=(估算涨停家数-估算跌停家数)/(估算涨停家数+估算跌停家数+20)`，常数固定为20，不另外缩放或改成百分比。MA5是当日及此前4个连续市场交易日各自S值的算术平均，不是先合计5日家数再套公式。

有效样本内涨跌停均为0时S=0；无样本、未知家数、负数、非整数或非有限值不伪填0。MA5须具备完整5个有效S值，且相邻previousTradeDate与上一行date相符。按原始日历行计算，再筛除低覆盖日期，避免跨越缺失/不可靠日期拼凑均线。周末和节假日按接口提供的市场日历自然衔接。

图表S使用红正绿负柱状，MA5使用金色线，纵轴-1到1，零轴作参考。只用于观察，不改变宽度状态、指数关系、策略评分或筛选。保留渐进加载和按需强势历史，不增加网络请求，不修改后端或数据库缓存。
