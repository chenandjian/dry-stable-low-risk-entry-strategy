# 市场宽度页面二次优化验收报告

## 1. 实施范围

- 重构 `/market-breadth` 的信息层级和图表交互。
- 新增前端市场宽度计算工具及单元测试。
- 保留现有真实历史接口、数据库结构和策略6历史信号数据。
- 未修改策略6评分、过滤、候选分类和扫描入口。

## 2. 核心口径

市场宽度统一为：

```text
上涨占比 = 上涨家数 / (上涨家数 + 下跌家数)
```

平盘和无法比较股票不进入分母。只有 `RELIABLE` 日期参与当前状态、MA5、趋势、历史分位、图表和弱势日期排行，低覆盖日期继续由接口返回，但不会污染研究结论。

## 3. 已完成功能

1. 页面首屏直接显示市场强弱、宽度趋势和“指数 × 个股”关系。
2. 增加上涨占比、MA5、最近5日变化、最近20日等级分布和120日历史分位。
3. 支持强势共振、指数虚强、个股强于指数、弱势共振和中性五类关系判断。
4. 四个真实宽基指数均保留，用户可切换主指数；历史图默认仅突出主指数。
5. 使用两张 ECharts 联动图展示上涨占比/MA5和指数涨跌，支持十字线、提示框、缩放和指数叠加。
6. 策略6历史正式候选以可关闭的金色标记叠加，继续明确标注“不参与策略6评分或过滤”。
7. 删除页面中的数据源名称和内部技术字段，提示框改为结论优先。

## 4. 有意未实施

未实现文档建议的“市场环境评分”。当前接口没有真实涨停/跌停结构，若在缺失该维度时强行给出10分制结果，会形成不完整且容易误导的伪精确评分。待真实字段具备后，应单独设计、测试和验收，且仍不得直接接入策略6。
