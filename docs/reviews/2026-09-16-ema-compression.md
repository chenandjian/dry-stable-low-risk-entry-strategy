# 批量评分 EMA 极致缠绕验收

新增独立 emaCompression 诊断字段和表格列；不进入引擎评分、扫描或生命周期。
支持确认状态、等级复选、评分范围、5日均宽上限、连续天数下限筛选；导出沿用当前筛选结果。

## 计算口径

- 前复权收盘计算 EMA5/10/20，以第一根收盘初始化，递归系数2/(N+1)。
- 带宽为(max EMA - min EMA)/mean EMA * 100，字段单位为百分数值。
- 100根预热，此前120个完整5日均宽样本，不含评价日；最低225根K线。
- 标准差采用样本标准差；历史分位采用历史值小于等于当前值的占比。
- 收紧比分母为零返回null并不给收紧加分；缺失历史返回空评分，不伪填零。
- 极致确认按文档七项门槛；非常极致须同时通过极致门槛，评分独立。
- 不实现含义尚未统一的首次进入/释放状态机。

## 配置

可通过 strategy6.ema_compression 覆盖默认配置，不改用户当前config.yaml。
extreme/ultra为七个上限，顺序：当前宽、3日均宽、5日均宽、5日最大、5日标准差、历史百分位、EMA20五日变化绝对值。
默认 extreme=[0.30,0.35,0.35,0.50,0.10,20,1.50]；ultra=[0.20,0.35,0.25,0.35,0.06,10,1.00]。
streak_threshold默认0.50。score_tables可覆盖七组[上限,分数]表，各组满分20/25/15/10/15/10/5。
配置异常返回CONFIG_INVALID，不影响正式引擎规则。EMA周期及观察窗口采用本版固定口径。
