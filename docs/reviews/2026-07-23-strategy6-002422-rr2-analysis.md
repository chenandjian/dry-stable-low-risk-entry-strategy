# 策略6个股核查：002422在2026-07-23的RR2

## 1. 结论

`RR2_LT_1_5` 在该日期并不表示系统计算出一个很低的实际盈亏比，而是交易计划未能建立，`objective_rr_2` 保持默认值0，随后统一触发了小于1.5的过滤。

股票被排除仍然正确，但该错误码对用户存在误导，应区分“没有有效交易计划”和“已计算的盈亏比不足”。

## 2. 当前计算链

策略6的盈亏比公式为：

```text
风险 = 计划入场价 - 止损价
目标2收益 = 客观目标2 - 计划入场价
RR2 = 目标2收益 / 风险
```

只有先识别出以下入场类型之一，才会继续计算入场、止损和目标：

- 支撑回调 `SUPPORT_PULLBACK`
- 枢轴突破 `PIVOT_BREAKOUT`
- 假突破收复 `FAILED_BREAKOUT_RECLAIM`
- 等待突破 `WAIT_BREAKOUT`

如果入场类型为 `NONE`，`calculate_trade_plan()` 直接返回空交易计划，入场、止损、目标和RR全部为0。

## 4. 为什么没有按“突破新高”计算

策略6的 `PIVOT_BREAKOUT` 不是只判断“收盘创阶段新高”，还要求：

1. 已识别形态必须提供有效枢轴价，当前 `pivot_price=0`。
2. 当前价必须突破枢轴，且不能超过枢轴8%以上。
3. 当前成交量必须达到20日均量的1.3倍，当前只有0.982倍。
4. 收盘位置必须不低于当日振幅的65%，该股当日为100%，此项通过。

该股虽然创了阶段最高收盘价，但没有突破7月6日的区间最高价52.78，也没有放量突破确认，因此不能进入枢轴突破交易模型。

## 5. 真正突破新高时的RR

如果后续形成有效枢轴并放量突破，策略会把止损放在枢轴下方，缓冲取枢轴1%与0.5倍ATR中的较大值；目标位按形态高度、ATR以及35%目标上限综合确定。

这种情况下风险通常较小、目标空间可能较大，RR2确实可能明显高于1.5。但“创新高”本身不保证高盈亏比，仍需要明确枢轴、止损和客观目标，不能仅凭价格处于新高就制造目标位。
