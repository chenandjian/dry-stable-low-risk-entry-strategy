# 策略6缓跌圆底集合形态实施报告

## 1. 实施范围

- 新增批量评分专用 `SLOW_ROUNDED_BASE_V2` 检测器。
- 新增可扩展 `klineCollectionPatterns` 输出容器。
- 批量评分页新增“K线集合形态”列、详情和字段筛选。
- 不修改策略6扫描入口、正式评分、资格、排序、候选分类和生命周期。

## 2. 判定口径

- 动态评估10-30个交易日窗口，每个窗口必须截至最新有效交易日。
- 603976 的2026-08-07至2026-08-26区间仅作为真实正样本，不固定13根K线或9.8%回撤。
- 评分覆盖缓跌质量15、下跌减速25、底部宽度20、低点后整理10、后段波动收缩12、收盘聚集8、K线重叠5、非V型5。
- 资格同时要求存在前期回调、下跌减速、底部有时间度、后段稳定、非V反且未明显拉离底部。
- 成交量萎缩只作为独立诊断特征，不影响形态分和匹配资格。

## 3. 真实数据验证

使用本地前复权数据库，以2026-08-26为截止日评估603976：

- 结果：`STRONG_MATCHED`
- 等级：A
- 得分：83.12
- 识别窗口：2026-08-12至2026-08-26，共11个交易日
- 窗口内回撤：7.30%；完整参考区间最大日内回撤仍为约9.8%
- 五个结构不变量全部成立。

默认批量输入的17只强势股以当前最新交易日评估时，5只匹配、12只未匹配或形成中。检测器能够区分当前尾部结构，不会为了命中参考样本而固定日期、幅度或路径。

## 4. 反例与兼容验证

- 相同天数和近似回撤的急跌V反：不匹配。
- 无有效回调的窄幅横盘：不匹配。
- 形态结束后已经显著上行的历史窗口：不返回陈旧匹配，结束日始终是最新交易日。
- 不同回撤深度、不同持续时间、左右不对称的缓跌圆底：允许匹配。
- API只新增字段，不删除或修改既有字段；旧前端数据缺少集合形态时显示“暂无集合形态诊断”。

## 5. 残余风险

- 缓跌圆底是宽泛价格行为家族。在全市场横截面普遍经历回调并横稳时，形态命中率可能偏高。因此当前功能只放在用户已筛选强势股的批量评分页，不作为全市场选股门槛。
- 当前只完成形态结构与真实样本验证，尚未用未来收益证明该形态具有独立交易价值。不得据此直接提升策略6正式候选等级。
- 动态窗口返回结构得分最高的当前子区间，不保证等于人工标注的完整回调起点；页面同时展示选中的起止日期供人工复核。
