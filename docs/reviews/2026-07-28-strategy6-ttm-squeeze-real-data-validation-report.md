## 6. 边界与防未来数据验证

- BB 必须严格位于 Keltner Channel 内部；任一边界相等均不算挤压。
- `TTM_SQUEEZE_3D_PLUS` 只在实际连续挤压达到 3 日时输出，不受可配置多头确认天数影响。
- 回测对个股和指数均按 `evaluation_date` 截断。
- 在评估日之后追加极端未来K线，评估日的 TTM 状态、加分、动量、BB上轨和KC上轨保持不变。
- 正式候选排序始终先按 `READY_CANDIDATE -> KEY_CANDIDATE -> WATCH_CANDIDATE`，TTM 仅在同一候选类型内排序。

## 7. 验收结论

实现满足“独立质量加分和同类排序”的定位，可以进入生产扫描并积累样本。正式候选资格仍完全由原策略6链路决定。

后续若要判断实际选股价值，应使用冻结策略入口做滚动历史回测，比较 TTM 高分组与 0 分组的胜率、盈亏比、Profit Factor、最大回撤及月度分布。在完成该验证前，不建议把 TTM 改为硬过滤，也不建议自动修改生产参数。
