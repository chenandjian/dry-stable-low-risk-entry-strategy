## 3. 错误码中文说明

| 错误码 | 含义 |
| --- | --- |
| `MA120_LE_MA250` | 120日均线不高于250日均线，长期趋势尚未转强 |
| `RS20_LT_0_1` | 相对宽基指数的20日强度低于10% |
| `NO_NEW_HIGH_CONFIRMATION` | 强启动缺少阶段新高确认 |
| `CLOSE_LE_MA250` | 收盘价不高于250日均线 |
| `CONSOLIDATION_TOO_LONG` | 当前启动事件后的整理时间超过策略上限 |
| `CONSOLIDATION_TOO_SHORT` | 强启动后整理时间不足 |
| `CONSOLIDATION_RANGE_5_GT_S_LIMIT` | S级启动后的5日整理振幅超过上限 |
| `CONSOLIDATION_RANGE_10_GT_S_LIMIT` | S级启动后的10日整理振幅超过上限 |
| `SUPPORT_FAILED` | 支撑结构整体不成立 |
| `NO_VALID_SUPPORT_TEST` | 没有找到有效的支撑测试 |
| `CLOSE_LT_KEY_SUPPORT` | 收盘价跌破关键支撑 |
| `BREAKOUT_EXTENDED` | 突破后涨幅已经超出允许追踪范围 |
| `BIG_DOWN_VOLUME` | 出现放量大跌 |
| `TAIL_NEW_LOW` | 尾部收盘创出相对前段的新低 |
| `TAIL_LOW_DECLINING` | 尾部后半段低点较前半段继续明显下移 |
| `TAIL_SINGLE_DROP_TOO_WEAK` | 尾部近3日出现超过允许值的单日收跌 |
| `TAIL_RETURN_5_TOO_WEAK` | 尾部5日累计收益过弱 |
| `TAIL_CLOSE_RANGE_GT_8PCT` | 最近5日收盘振幅超过8% |
| `TAIL_VOLUME_NOT_DRY` | 尾段均量相对尾段前20日没有收缩到75%以内 |
| `RR2_LT_1_5` | 客观目标2对应的预估盈亏比低于1.5，或交易计划无法成立而为0 |

## 4. 阶段性结论

1. 5月22日至6月30日，最稳定的结构性障碍是 `MA120_LE_MA250`，同时多日相对强度不足。
2. 7月1日至6日，股价启动较强，但长期均线结构仍未完成确认。
3. 7月7日至13日出现放量下跌且整理时间不足，不能立即作为稳定尾部。
4. 7月14日至23日，长期趋势障碍逐步消失，但尾部波动和量能仍不合格。
5. 截至7月23日，最直接的三个障碍是5日收盘振幅过大、尾部未量干、未形成有效交易计划。
