## 5. 推荐方案

### 推荐采用：`keep_today_f`

理由：

1. 相比基线，20日平均收益从 `-0.19%` 提升到 `3.49%`。
2. 20日 PF 从 `0.97` 提升到 `1.74`。
3. 20日胜率从 `41.23%` 提升到 `50.30%`。
4. 平均最大回撤从 `-10.03%` 改善到 `-8.76%`。
5. 事件数从 308 降到 169，收紧明显但不至于没有样本。
6. 当前 2026-07-08 仍保留 1 只观察候选，不会出现今日扫描完全无候选。

### 不建议直接采用：`quality_combo`

`quality_combo` 的最差回撤更好，但它会清空今日候选，且事件数只有 104。作为高质量版本可以保留为后续“严格模式”，但不建议直接替换默认策略5参数。

## 6. 需要进一步开发的方向

本轮只做合法配置参数实验，没有修改代码。归因显示策略5还有两个结构性问题，后续可单独开发：

1. `KEY_CANDIDATE` 历史表现明显弱于 `WATCH_CANDIDATE`，说明当前 KEY 定义偏激进。
2. MA5 / MA10 支撑历史表现差，MA20 / MA50 更好。策略5可能需要新增“支撑成熟度”或“回调充分度”过滤层，避免强势冲刺刚回 MA5 就过早入选。
