# 策略6 Brooks 尾部路径专项回测与参数调优报告

## 1. 结论

本轮只评估策略6新增的 Brooks 尾部路径。原始尾部和箱体路径不进入信号范围；当一条记录同时命中旧路径与 Brooks 时，只有 `brooks_trade_ready=true` 才允许生成 Brooks 研究订单。

最终结论：**不调整任何 Brooks 正式参数，不写入 `config.yaml`。**

原因：

1. 2023-2024 训练抽样中，正式基线只有 3 条日候选、1 笔闭合交易，样本不足。
2. 12 个单参数放宽均未改变闭合交易数量或收益。
3. 12 个参数全部联合放宽后，训练段从 1 笔增至 2 笔，但新增交易亏损，PF 从无穷值（仅一笔盈利，统计无意义）降为 0.775。
4. 2025 保留期中，正式基线 7 笔闭合交易，期望为 -0.919R；联合放宽 11 笔，期望为 -0.918R，最大回撤从 6.45% 扩大到 8.87%。
5. 2025 基线 7 笔交易全部与 ORIGINAL/BOX 重叠，没有 Brooks-only 闭合交易贡献；联合放宽新增的 Brooks-only 闭合交易均为亏损。

因此，当前真实数据不支持“Brooks 路径能够提升策略6收益”，更不支持放宽参数。Brooks 路径可以继续保留为观察和多路径解释能力，但不能凭本轮结果升级正式阈值。

## 2. 回测口径

| 项目 | 口径 |
| --- | --- |
| 数据库 | `data/cuphandle.db` |
| 个股数据 | 本地 `daily_ohlc`，前复权 |
| 指数数据 | 本地真实 `market_index_ohlc` |
| 指数 | 上证指数、深证成指、创业板指、沪深300 |
| 数据版本 | `d8dd32ef3e92fd732a7a0f6cbe7b9abb186fe6562fe8645eaf371c42d26624a4` |
| 最少历史 | 500 个交易日 |
| 执行模型 | 冻结交易计划、T+1、佣金/税费/滑点、最长持有20日 |
| 研究范围 | `BROOKS_PATH` |

`BROOKS_PATH` 包含纯 Brooks 与 Brooks/旧路径重叠信号，但订单必须由 Brooks 自身触发。这样既不会把 ORIGINAL/BOX 单独命中混入 Brooks 结果，也不会错误丢弃 Brooks 与旧路径重叠的真实样本。

### 连续触发窗口

Brooks 触发有效期只有数个交易日，不能采用每20日只评估单日的普通稀疏采样，否则会漏掉跨日确认。

本轮使用“锚点 + 后续3个交易日”的连续窗口：

- 训练：2023-2024，每20个交易日一个锚点，共100个评估日。
- 验证：2025，每10个交易日一个锚点，共99个评估日。
- 所有窗口都按 `evaluation_date` 截断个股和指数数据，没有读取未来K线。

该方法保留短触发生命周期并降低全市场调参成本，但仍不是每日全量回放，因此结果只具有 `RESEARCH_ONLY_CURRENT_UNIVERSE` 可信度。

| 方案 | 日候选 | 唯一股票 | Brooks-only候选 | 闭合交易 | 胜/负 | 期望R | PF |

训练基线唯一闭合交易为 `000426`，收益 7.04%，结果 1.278R。仅靠这一笔盈利不能估计胜率、PF或参数稳定性。

## 6. 参数决策

### 保持原值

本轮12个 Brooks 参数全部保持正式值。理由：

1. 单参数变化没有表现出收益敏感性。
2. 联合放宽虽然扩大候选，但训练和验证均引入额外亏损。
3. 验证期基线本身为负期望，不能从“较差”和“更差”中选一个升级。
4. 交易样本少且高度集中，无法满足最少20笔训练交易的调优门槛。
5. OOS未解锁，禁止用2026数据挑选参数。

### 不建议的做法

- 不要降低正式通过分来追求候选数量。
- 不要扩大支撑距离或触发ATR距离。
- 不要延长假跌破恢复时间。
- 不要把多路径重叠收益归功于 Brooks 增量。
- 不要根据训练段单笔盈利宣称高PF。
- 不要把2025验证结果反向用于继续搜索更多组合。

## 8. 验证与风险

专项代码验证：

```text
Strategy6 tests: 332 passed
compileall: passed
```

已确认：

1. Brooks研究作用域进入任务指纹，不会跨作用域错误复用缓存。
2. Brooks路径研究不会接纳 ORIGINAL/BOX 单独命中。
3. 多路径记录必须由 Brooks 自身 `brooks_trade_ready` 才能下单。
4. 训练、验证、OOS日期严格隔离。
5. 连续窗口覆盖3日触发有效期。
6. 正式配置没有自动写入。

残余风险：

1. 股票池存在幸存者偏差，历史ST、退市和停牌状态不完整。
2. 连续窗口抽样不是逐日全量回放，可能漏掉锚点窗口之外的机会。
3. 前复权价格用于统一研究；真实成交可交易性仍受涨跌停、停牌及实际盘口影响。
4. 样本量不足以评价不同 Brooks 结构的长期稳定性。
5. 训练实验运行时回测工具尚未提交，记录的策略提交为父提交 `622569c`；2025验证已在实际工具提交 `0dcdae8` 上重跑并作为最终否决依据。

## 9. 最终验收

本轮回测与调优已完成，但参数升级条件未满足。Brooks 新路径当前应保持“研究/观察能力”，正式扫描参数维持不变。后续只有在积累更多真实历史或完成逐日全量回放后，才有理由重新申请参数实验；不能为了增加候选而放宽当前风控。
