## 4. 阻塞点

### BLOCKER-001：沪深300历史K线缺失

涉及模块：`market_index_ohlc`、`strategy6/backtest/index_history.py`。

当前实现要求四个真实指数覆盖训练和验证区间。沪深300逻辑键必须映射真实 `sh000300`，不得回退上证或等权代理。

联网补数未执行，原因是Codex外部执行审批提示当前使用额度已达上限。该失败发生在网络请求前，数据库没有被此次请求修改。

继续执行风险：若关闭市场过滤或使用代理指数，E0不再代表生产策略，BOX参数收益结论无效。

建议解决：额度恢复后执行：

```bash
python -m strategy6.backtest.cli fetch-index --db data/cuphandle.db --start 2023-01-01 --end 2025-12-31
```

覆盖验证通过后再运行 `baseline`、`experiments` 和受限 `optimize`。
