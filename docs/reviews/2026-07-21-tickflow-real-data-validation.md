# TickFlow真实六股批量日线验证报告

## 1. 验证结论

TickFlow独立批量模块通过真实网络、临时SQLite和腾讯/AkShare-Sina三源对照验证，可以进入独立CLI使用阶段。本次没有修改生产数据库，也没有把TickFlow接入现有扫描和调度链。

- 六只股票均成功获取800根`1d`、`forward_additive`日线。
- 首次回填全部使用`full`，第二次运行全部使用10根重叠窗口的`incremental`。
- 第二次运行后每只股票仍为800根，最新日期均为`2026-07-21`，没有误判复权变化或重复数据。
- 临时库重复`(code, date)`为0，非法OHLC为0，元数据来源均为`tickflow`。
- TickFlow与腾讯近20个共同交易日最大OHLC相对偏差为`1.96e-7`。
- TickFlow与AkShare-Sina近20个共同交易日最大OHLC相对偏差为`0.0565%`，发生在`600519`，价格路径和日收益差仍低于`0.01%`。
- 成交量已从TickFlow“手”转换为“股”；与两源最大相对偏差不超过`0.00132%`。

## 6. 残余风险

1. `TickFlow.free()`只承诺历史日线，不提供盘中实时数据；独立CLI适合收盘后更新，不能替代盘中实时行情。
2. `forward_additive`与比例前复权可能在发生新的除权除息后整体变化。模块通过重叠窗口首个共同日检测变化，并自动升级整段重拉。
3. 本阶段TickFlow没有接入扫描器、调度器和前端，这是有意隔离；生产扫描仍使用原腾讯/Sina/Baidu链。
4. 本次真实样本为六股和800根，已覆盖沪深主板、创业板和科创板；全市场吞吐和服务端限流仍需在正式批量运行时观察报告。
