# 策略6双路径历史回测与参数调优最终报告

## 1. 结论

本轮结论为 **KEEP_DEFAULT / REJECT_BOX_EXPANSION**：保留策略6现有生产配置，不把本轮箱体参数试验升级为正式参数，也不运行锁定的2026年OOS。

原因：默认双路径和3组真实参数试验均未同时达到 `交易数>=100、期望R>=0.05、PF>=1.10、最大回撤<=25%`。默认BOX-only明显负期望；表面最好的试验3只有44笔组合成交，PF 0.94，且训练期优势在2025验证期消失。

- 每轮4793只完成评估，736只因不足500根历史K线跳过，无评估失败。
