# 策略6强势趋势收缩初筛实施验收报告

## 1. 检查范围

- 策略6统一入口与长期趋势硬过滤
- EMA150、EMA200、250交易日高低位计算
- BB20/KC20正式收缩条件
- 强势启动事件保留情况
- 候选字段、SQLite兼容迁移、批量评分与结果页展示
- 策略6回测和历史逐日重放入口一致性
- 后端、前端和构建回归

## 2. 总体结论

本次实现完整替换了旧的 `close > MA250`、`MA120 > MA250` 长期趋势门槛，同时保留策略6原有强势启动事件、阶段、形态、支撑、尾部和盈亏比链路。新初筛为固定正式规则，不可通过旧TTM诊断配置绕过；截至本次验收未发现中高等级遗留问题。

## 3. 正式规则

评估日使用截至当日的本地前复权日线，并要求以下条件全部成立：

1. `close > 10`
2. `close >= 最近250交易日最低low * 1.30`
3. `最近250交易日最高high * 0.70 <= close <= 最近250交易日最高high`
4. `EMA150 > EMA200`
5. `close > EMA150`
6. `close > EMA200`
7. BB20完全位于KC20内：`BB_Upper < KC_Upper AND BB_Lower > KC_Lower`

BB使用20日SMA与2倍总体标准差；KC使用EMA20中轨、Wilder ATR20和1.5倍ATR宽度。EMA使用首个完整周期SMA作为种子，之后按 `2/(N+1)` 递推。

## 4. 兼容性结论

- 策略6入口仍为 `StrongVcpTailEngine.evaluate_at()`。
- 强势启动的涨停、放量突破和动量启动识别未删除、未放宽。
- 旧候选字段和API未删除；新增字段通过SQLite兼容迁移追加。
- 旧任务没有新字段时保持空值，前端显示“旧任务未计算”，不会伪造为不通过。
- 扫描、批量评分、VCP历史逐日重放和策略6回测继续共用统一引擎。
- 可配置TTM模块保留为附加诊断，但其分数不再参与资格、100分总分或排序，避免收缩条件重复计分。
- 策略版本升级为 `4.10.0`。
