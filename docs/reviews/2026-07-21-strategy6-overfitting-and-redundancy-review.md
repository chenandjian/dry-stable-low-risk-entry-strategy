## 2. 总体结论

策略6存在明显的**模型复杂度过高、实验规则进入正式链、同一证据重复使用**问题。没有发现回测直接读取未来K线的证据；真正的过拟合风险来自规则和参数持续叠加、反复使用2023-2025样本、以及历史实验已经否定的能力仍在当前扫描入口启用。

建议先做规则治理和消融验证，不要继续搜索更多阈值。

## 4. 详细问题分析

### S6-001：被否决的质量V2行为仍在正式扫描链启用

#### 证据

1. `strategy6/engine.py` 当前入口无版本开关地执行动态尾段、`evaluate_setup_quality()`、新评分和分类交易计划。
2. `strategy6/scorer.py` 固定输出 `score_model_version="S6_QUALITY_V2"`。
3. `strategy6/validation.py` 默认启用 `dynamic_tail_enabled=True`，并定义质量门槛。
4. `2026-07-14-strategy6-main-chain-quality-optimization-report.md` 的审批结论却是：
   - `REJECT_QUALITY_V2_FOR_PRODUCTION`
   - `KEEP_CURRENT_FORMAL_BEHAVIOR_UNCHANGED`
   - B5训练期 `-0.620R / PF 0.637`
   - B5验证期虽为 `+0.149R`，但 `PF 0.693`
   - 三类压力测试全部失败
5. 报告对应提交 `6a8a839`、`783d08c` 均为当前 `HEAD ff7e09e` 的祖先，当前入口实际包含这些实验能力。

#### 影响

报告说“不升级”，代码却没有正式/研究版本隔离。用户点击策略6扫描时执行的是质量V2，而不是报告批准保留的旧正式行为。最近任务保存的18条记录也全部标记为 `S6_QUALITY_V2`。

#### 修复建议

建立明确的 `formal_rule_version`：

- 正式扫描默认使用最后获批的稳定规则版本。
- 动态尾段、质量V2和分类交易计划只能通过研究模式显式开启。
- 保留所有新增输出字段；正式旧版本无法计算的字段用 `null/未评估`，不得伪造为0。
- 在完成新一轮预注册消融验证前，不允许用配置默认值间接开启被否决模型。

### S6-002：BOX负增量且成为KEY的隐性必要条件

#### 证据

`combine_tail_paths()` 当前计分：

- ORIGINAL通过：10分
- BOX通过：3分
- Brooks交易触发：2分
- 两条以上路径：2分
- 上限15分

`classify_candidate()` 又要求KEY候选 `tail_score >= 15`。最小可达组合实际上是 `ORIGINAL + BOX + 多路径奖励 = 15`。ORIGINAL单独通过只能得到10分；即使原始尾部质量满分20，也不能成为KEY。

最小规则探针结果：

```text
original_only_tail_score=10
original_plus_box_tail_score=15
```

历史BOX报告却显示：

- 原路径E0：31笔，期望 `-0.108R`，PF `0.834`
- 默认双路径E1：184笔，期望 `-0.275R`，PF `0.537`
- BOX-only新增153笔，期望 `-0.310R`，PF `0.483`
- 报告结论：`REJECT_BOX_EXPANSION`

#### 影响

被历史数据否定的BOX不仅仍默认启用，还通过15分门槛与KEY等级绑定。它同时可能让部分原始尾部失败项被辅助路径绕过，并制造大量解释字段和候选噪声。

#### 修复建议

- 正式模式默认关闭BOX作为独立通过路径，保留BOX指标作为研究标签。
- 移除 `tail_score>=15` 对BOX的隐式依赖；如果业务确实要求多路径确认，应增加命名明确的 `require_multi_path_for_key`，并在历史增量验证通过后才能开启。
- ORIGINAL的路径质量应基于自身质量分或独立等级，不应固定为10后再依赖辅助路径凑满。
- BOX-only不得绕过原始路径的核心结构性风险。

### S6-003：真实0分绕过质量门槛

#### 证据

`strategy6/filters.py::_quality_threshold_met()` 当前实现：

```python
return value == 0 or value >= threshold
```

实际探针：

```text
quality_zero_passes_14=True
quality_zero_passes_18=True
```

代码注释希望0兼容旧调用方，但当前引擎会真实计算 `setup_quality_score` 和 `support_reaction_score`。0既可能表示旧字段缺失，也可能表示真实质量极差，两个语义被合并。

#### 触发条件

- 启动涨幅保留差、派发日多、下跌量占优、波动不收缩、RS趋势不可用时，真实setup质量可以为0。
- 没有有效支撑测试时，支撑反应分可以为0。

#### 影响

0分反而绕过KEY/READY的14/18或3/5门槛。由于其它维度最高可把总分推到KEY附近，这不是纯理论问题。

#### 修复建议

- 数据模型将“未计算”改为 `None` 或增加 `setup_quality_observed`、`support_reaction_observed`。
- 只有旧任务读取兼容层可以把缺失字段解释为未评估。
- 当前引擎产生的真实0分必须严格不通过正数门槛。
- 增加0分、缺失值、边界值三组测试。

### S6-004：`watch_min_score` 对成熟候选失效

#### 证据链

1. 硬过滤先拒绝 `objective_rr_2 < rr2_min_watch`。
2. 没有硬拒绝的成熟候选必然满足 `objective_rr_2 >= rr2_min_watch`。
3. WATCH判断使用：`score >= watch_min_score OR rr2 >= rr2_min_watch`。
4. 因此第二项对所有非拒绝成熟候选恒为真，`watch_min_score=60` 不会改变候选资格。

`START_TOO_RECENT` 在RR过滤前提前返回并单独进入WATCH，不改变上述成熟候选结论。

#### 修复建议

二选一并固定语义：

- 推荐：RR继续作为硬底线，WATCH再要求 `score >= watch_min_score`。
- 或者删除 `watch_min_score`，明确WATCH等于“通过所有硬过滤但未达到KEY”。

不要继续在全面调优中搜索一个逻辑上不起作用的参数。

### S6-005：同一证据被重复处罚或重复奖励

主要重复如下：

| 证据 | 硬过滤 | 评分 | 分层再次判断 |
| --- | --- | --- | --- |
| RR2 | `<1.5`拒绝 | 0-10分 | KEY>=2、READY>=2.5 |
| RS/市场 | RS20<0.1拒绝 | RS/风险分；setup质量含RS趋势 | 弱市降级KEY/READY |
| 支撑测试 | 至少1次；破位拒绝 | cluster分含测试；reaction分再次计测试 | KEY/READY再设reaction门槛 |
| 尾部量缩 | 原路径拒绝 | tail路径分 | READY再要求<=0.60 |
| 强势启动 | 类型+新高硬门槛 | 启动分 | B级禁止KEY/READY，Brooks再限制等级 |
| 放量大跌 | 硬拒绝 | 风险分扣分 | `major_risk`再次阻止KEY/READY |

其中“放量大跌”的后续评分和等级检查对已被硬拒绝的股票没有决策作用；支撑测试在cluster、reaction、硬过滤和等级门槛中重复出现；RR同时控制准入、总分和等级，权重远高于表面上的10分。

#### 修复建议

为每个证据确定唯一主职责：

- 灾难性风险：只做硬拒绝，不再通过评分重复扣分。
- 连续质量指标：只做评分，等级通过总分体现。
- 交易可行性（RR、止损、目标）：保留等级硬底线，但不要再让相同阈值重复决定WATCH总分。
- 仅解释指标：不参与准入和分层。

### S6-006：Brooks正式路径缺少独立收益证据

Brooks专项报告显示：

- 训练基线只有1笔闭合交易。
- 2025基线7笔全部与ORIGINAL或BOX重叠，没有Brooks-only闭合贡献。
- 联合放宽新增4笔交易全部亏损。
- 报告明确建议仅保留观察和多路径解释能力。

当前默认配置仍为 `brooks_tail.enabled=true`，每只股票都会计算上下文、卖压、稳定、量缩、支撑、二次入场、失败突破、紧密结构和触发，配置约60项。它还复用/强制计算BOX紧密K线指标，进一步增加路径耦合。

#### 修复建议

- 正式扫描默认只计算Brooks解释标签，不能作为独立通过路径或分数来源。
- 提供研究开关，专项研究时才执行完整触发链。
- 若性能测量证明开销明显，可在正式扫描中延迟计算：仅对已通过主链基础门槛的股票计算解释字段。

### S6-007：参数/样本比过高，验证集已被污染

- 当前策略6配置约191个叶子参数。
- 全面调优测试164组OAT，七阶段均未选出合格参数。
- 最终逐日回测训练期仅19笔闭合交易，验证期158笔。
- 训练 `-0.5118R / PF 0.5836`，验证 `-0.2593R / PF 0.5117`。
- 2025被BOX、Brooks、质量V2和全面调优多轮反复用于判断，已不再是纯粹的独立验证集。
- 当前股票池存在幸存者偏差，历史证券状态不完整。

#### 判断

这是高过拟合风险，但不是“某次搜索挑中了训练期最好参数”的传统过拟合，因为实验没有选出合格参数。更准确地说，是**高复杂度、低证据、反复观察后的研究性规则被保留在生产链**。

#### 修复建议

- 正式参数目标先缩减到30-50个；其余转为研究参数或派生值。
- 2025不得继续作为新方案的独立验证证明。
- 在不查看2026收益的前提下先冻结规则、指标、退出模型和验收门槛，再一次性解锁OOS；若不准备正式决策，则继续锁定。
- 使用滚动walk-forward、按年份/市场状态分层、参数扰动和候选增量归因，而不是继续做同一样本上的微调。

### S6-008：形态过滤开关语义不完整

当前 `pattern_filter_mode=score_only`：

- `pattern_filter_enabled` 只在strict硬过滤和downgrade分支中被读取。
- scorer无论开关值如何都会加入pattern分。
- 因此在score_only模式中，开关本身不会关闭形态评分。

最近任务18条保存记录全部为 `pattern_type=UNKNOWN`，其中仍有1条WATCH，说明当前策略名义上的VCP/杯柄/平台不是观察池准入必要条件。

#### 修复建议

- 将“形态是否参与评分”和“形态是否过滤/降级”拆成两个命名明确的配置。
- 或定义关闭开关后pattern分固定为0，并补充三种mode的参数化测试。
- 明确策略6正式定义：UNKNOWN是否允许WATCH、是否允许KEY/READY。

## 5. 哪些规则暂时不应删除

以下能力虽然也有阈值，但具有清晰独立职责，不建议在没有消融实验前直接删除：

1. 前复权数据完整性与最少交易日门槛。
2. 灾难性风险：放量大跌、关键支撑有效跌破、连续收盘跌破、MA长期趋势破坏。
3. 启动、整理、尾段不重叠的As-Of阶段边界。
4. 客观目标、止损和NEXT交易日执行语义。
5. 市场真实指数快照、弱市降级和缺失指数保护。
6. VCP观察池历史正式候选资格；它与正式候选主链隔离，当前只用于观察和排序。

这些规则可以精简重复判断，但不能为了增加候选直接取消核心风控。

## 6. 推荐精简方案

### 第一阶段：修复规则语义，不调参数

1. 修复真实0分绕过质量门槛。
2. 明确WATCH分数和RR的关系，删除一个冗余条件。
3. 解除KEY对BOX的隐式依赖，改成显式、可审计规则。
4. 拆分形态评分开关与形态过滤模式。
5. 保持旧API和字段兼容。

### 第二阶段：正式链与研究链隔离

建议形成以下消融组：

| 组别 | 正式能力 |
| --- | --- |
| A0 | 强势启动 + 趋势/流动性 + 原始尾部 + 支撑 + 客观RR + 市场降级 |
| A1 | A0 + BOX解释标签，不参与通过/评分 |
| A2 | A0 + Brooks解释标签，不参与通过/评分 |
| A3 | A0 + setup质量解释标签，不参与通过/评分 |
| A4 | 只加入经过增量验证的单个能力 |

不要一次比较“旧版”和“全部增强版”，必须逐层记录新增/删除候选及增量交易贡献。

### 第三阶段：预注册验证

每项新能力至少满足：

1. 唯一增量闭合交易样本达到预设最低数量，建议不少于30笔；不足只能保留标签。
2. 多个训练滚动窗口方向一致，不依赖单一年份或单月。
3. 期望R>0、PF>=1.20、平均盈亏R比>=2.5。
4. 参数上下扰动10%-20%后方向不反转。
5. 高成本、70%成交率、延迟一天至少不出现全面失效。
6. 不读取2026 OOS进行筛选或反复试错。

## 7. 测试与验收计划

### 单元测试

- `setup_quality_score=0` 必须不通过正数质量门槛。
- `None/旧任务缺失` 只能在兼容读取层显示未评估，不影响新任务。
- ORIGINAL-only的KEY行为必须符合显式策略，不得由BOX分数偶然决定。
- 改变 `watch_min_score` 必须能改变边界样本分类，或正式删除该参数。
- pattern评分开关关闭后，pattern分必须按文档处理。
- BIG_DOWN_VOLUME只保留一条决策路径，但风险标签和拒绝原因仍可解释。

### 集成测试

- 同一组固定K线分别运行正式模式和研究模式，旧API字段完全兼容。
- BOX/Brooks关闭后不得影响ORIGINAL判断结果。
- VCP观察池继续不影响正式评分和候选资格。
- 策略1至策略5测试保持通过。

### 历史验证

- 每组产出逐日候选、订单、交易、被删候选、新增候选和月度分布。
- 单独报告路径唯一贡献，不把多路径重叠收益归给新增路径。
- 保留真实四指数、T+1、涨跌停、停牌、费用和STOP_FIRST语义。
